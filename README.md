# Separate Web CTF Challenges

Six independent Flask apps, each in its own folder and listening on a separate localhost port.

| Folder | Difficulty | Port |
|---|---|---:|
| `01-view-from-shadows` | Easy | 5001 |
| `02-cookie-crumbs` | Easy | 5002 |
| `03-query-quake` | Medium | 5003 |
| `04-forgotten-backup` | Medium | 5004 |
| `05-template-of-doom` | Hard | 5005 |
| `06-zero-trust` | Hard | 5006 |

Each folder has its own `app.py`, `requirements.txt`, `README.md`, `PLAYER.md`, and `WRITEUP.md`. Run them independently. Keep write-ups private until the event is over.
